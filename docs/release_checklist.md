# ScholarCheck Release Checklist

이 체크리스트는 ScholarCheck MVP 릴리즈 전 점검 항목입니다.

## 1. 코드 상태

- [ ] 작업트리가 clean 상태인지 확인한다.
- [ ] 최신 `main` 브랜치 기준인지 확인한다.
- [ ] 새 기능이 원본 세션 JSON을 임의 수정하지 않는지 확인한다.
- [ ] 누락값을 임의 보완하지 않는지 확인한다.
- [ ] 국내 DB 수동 기록이 자동 검증 논문 목록과 섞이지 않는지 확인한다.

명령:

```powershell
git status --short
git log -1 --oneline
```

## 2. 테스트

- [ ] 전체 pytest가 통과한다.
- [ ] API 실패 시 가짜 결과를 만들지 않는다.
- [ ] DOI 누락 시 `UNKNOWN` 또는 null로 유지한다.
- [ ] PDF URL 누락 시 직접 가능으로 표시하지 않는다.
- [ ] 제외 키워드 결과가 제거된다.
- [ ] 국내 DB 링크가 자동 검증 논문 목록에 포함되지 않는다.
- [ ] 세션/프로젝트 출력이 수동 기록과 자동 결과를 분리한다.

명령:

```powershell
python -m pytest
```

현재 릴리즈 기준 기대값:

```text
31 passed
```

## 3. CLI 점검

- [ ] 기본 검색이 실행된다.
- [ ] CSV 출력이 생성된다.
- [ ] JSON 출력이 생성된다.
- [ ] 검색 결과 부족 시 완화 제안이 생성된다.
- [ ] API 오류가 발생해도 가짜 논문을 생성하지 않는다.

예시:

```powershell
python -m scholarcheck "artificial intelligence education" --required "artificial intelligence, education" --helpful "teacher, curriculum" --exclude "patent, news" --limit 10 --format csv
```

## 4. 웹 UI 점검

- [ ] 웹 서버가 실행된다.
- [ ] 검색 중 로딩 표시가 보인다.
- [ ] 결과 없음 안내가 보인다.
- [ ] 오류 발생 시 오류 메시지가 보인다.
- [ ] CSV 다운로드 버튼이 동작한다.
- [ ] JSON 다운로드 버튼이 동작한다.
- [ ] 국내 DB 링크 영역이 자동 검증 결과와 분리되어 보인다.
- [ ] 상세 보기 화면이 열린다.
- [ ] DOI 재검증 버튼이 동작한다.
- [ ] 인용 전 체크리스트가 표시된다.

명령:

```powershell
python -m scholarcheck.web
```

주소:

```text
http://127.0.0.1:8765
```

## 5. 세션 출력 점검

- [ ] 검색 결과를 세션으로 저장할 수 있다.
- [ ] 저장 세션 목록을 볼 수 있다.
- [ ] 저장 세션을 다시 열 수 있다.
- [ ] 세션 HTML 리포트를 다운로드할 수 있다.
- [ ] 세션 Excel 통합 파일을 다운로드할 수 있다.
- [ ] 참고문헌 후보가 최종 확정본이 아님을 표시한다.
- [ ] 선행연구 매트릭스의 연구목적, 연구방법, 연구대상, 주요결과가 자동 추정되지 않는다.

## 6. 프로젝트 출력 점검

- [ ] 새 연구 프로젝트를 만들 수 있다.
- [ ] 저장 세션을 프로젝트에 연결할 수 있다.
- [ ] 프로젝트 상세 화면에서 연결된 세션 목록을 볼 수 있다.
- [ ] 프로젝트 HTML 리포트를 다운로드할 수 있다.
- [ ] 프로젝트 Excel 통합 파일을 다운로드할 수 있다.
- [ ] 중복 논문이 삭제되지 않고 `duplicate_candidate`로 표시된다.
- [ ] 누락 세션이 Missing Sessions에 표시된다.
- [ ] 누락 세션에 대해 가짜 세션이나 가짜 논문을 생성하지 않는다.
- [ ] 국내 DB 수동 기록은 별도 영역이나 별도 시트로 유지된다.

## 7. Excel 점검

- [ ] 파일이 정상적인 `.xlsx` ZIP 패키지로 열린다.
- [ ] 첫 행이 헤더로 표시된다.
- [ ] 첫 행이 고정되어 있다.
- [ ] 자동 필터가 적용되어 있다.
- [ ] 열 너비가 읽기 어렵지 않다.
- [ ] 긴 텍스트가 줄바꿈된다.
- [ ] Warnings 시트에 필수 안내가 포함된다.
- [ ] 한글 텍스트가 깨지지 않는다.

## 8. 문서 점검

- [ ] README의 실행 방법이 최신 상태다.
- [ ] `docs/user_guide.md`가 사용자 흐름을 설명한다.
- [ ] `docs/architecture.md`가 주요 모듈과 데이터 경계를 설명한다.
- [ ] `docs/development_history.md`가 MVP별 변경 이력을 설명한다.
- [ ] `docs/release_checklist.md`가 릴리즈 전 점검 항목을 담고 있다.
- [ ] 샘플 검색 시나리오 문서가 연결되어 있다.

## 9. 릴리즈 원칙

릴리즈 전 다음 문구와 원칙이 유지되는지 확인합니다.

- ScholarCheck는 외부 API 메타데이터 기반 검증 보조 도구입니다.
- 최종 인용 전 원문 페이지 확인이 필요합니다.
- 참고문헌 후보는 자동 확정본이 아닙니다.
- 선행연구 매트릭스의 연구목적, 연구방법, 연구대상, 주요결과는 자동 추정하지 않습니다.
- 국내 DB는 자동 크롤링하지 않습니다.
- 국내 DB 수동 기록은 사용자가 직접 입력한 메모이며 자동 검증 결과가 아닙니다.
- PDF 가능 여부는 API의 PDF URL 확인 기준입니다.
