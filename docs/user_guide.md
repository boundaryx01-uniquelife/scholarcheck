# ScholarCheck User Guide

ScholarCheck는 논문 검색과 검증을 보조하는 MVP 도구입니다. 이 도구는 논문 존재 여부를 최종 보증하지 않으며, Crossref와 OpenAlex 같은 외부 API 응답을 기준으로 메타데이터를 정리합니다.

최종 인용 전에는 반드시 원문 페이지에서 제목, 저자, 연도, 학술지, DOI, 권호, 페이지, PDF 접근 가능 여부를 다시 확인해야 합니다.

## 기본 실행

CLI 검색:

```powershell
python -m scholarcheck "artificial intelligence education" --required "artificial intelligence, education" --helpful "teacher, curriculum" --exclude "patent, news" --limit 10
```

웹 UI 실행:

```powershell
python -m scholarcheck.web
```

기본 주소:

```text
http://127.0.0.1:8765
```

다른 포트를 쓰려면 다음처럼 실행합니다.

```powershell
python -m scholarcheck.web --port 8770
```

## 추천 사용 흐름

1. 연구 주제와 필수/도움/제외 키워드를 입력합니다.
2. 검색 결과에서 DOI, 원문 URL, PDF URL, 초록, 인용 수, 점수, 주의사항을 확인합니다.
3. 각 논문 상세 화면에서 DOI 재검증과 인용 전 체크리스트를 확인합니다.
4. 결과를 CSV 또는 JSON으로 내려받습니다.
5. 필요한 검색은 세션으로 저장합니다.
6. 저장 세션에서 참고문헌 후보와 선행연구 매트릭스 초안을 확인합니다.
7. 세션 단위 HTML 리포트 또는 Excel 통합 파일을 생성합니다.
8. 여러 세션을 연구 프로젝트로 묶습니다.
9. 프로젝트 단위 HTML 리포트 또는 Excel 통합 파일을 생성합니다.
10. 국내 DB 링크와 수동 확인 기록은 별도로 검토합니다.

## 검색 조건 작성 팁

필수 키워드는 논문 제목과 초록에서 강하게 반영됩니다. 너무 좁게 넣으면 검색 결과가 줄어들 수 있습니다.

도움 키워드는 보조 점수로 반영됩니다. 관련 분야, 대상, 방법, 맥락을 넣는 데 적합합니다.

제외 키워드는 제목이나 초록에 포함되면 결과에서 제외됩니다. `patent`, `news`, `blog`처럼 연구 논문이 아닌 자료를 줄이는 데 유용합니다.

검색 결과가 부족하면 ScholarCheck는 가짜 결과를 만들지 않고 검색 조건 완화 제안을 출력합니다.

## 결과 화면 해석

`UNKNOWN`은 내부 데이터와 CSV/JSON 출력에서 누락값을 나타냅니다. 웹 화면에서는 같은 의미를 사용자 친화적으로 `확인 불가`로 표시합니다.

PDF 가능 여부는 PDF URL이 확인된 경우에만 직접 가능으로 표시합니다. PDF URL이 없으면 직접 다운로드 가능으로 과장하지 않습니다.

인용 수가 높은 오래된 논문은 고전 후보로 별도 표시될 수 있습니다. 이는 중요한 선행연구일 수 있다는 신호이며, 자동 확정 판단은 아닙니다.

## DOI 재검증

논문 상세 화면에서 DOI 재검증을 실행할 수 있습니다. 재검증은 Crossref 응답과 현재 논문의 제목, 연도, 출처 정보를 비교합니다.

대표 상태:

- `verified`: DOI와 핵심 메타데이터가 대체로 일치합니다.
- `mismatch`: DOI 조회 결과와 현재 논문 정보가 크게 다릅니다.
- `missing`: DOI가 없어 재검증하지 않았습니다.
- `not_found`: Crossref에서 DOI를 찾지 못했습니다.
- `error`: API 오류나 네트워크 문제로 확인하지 못했습니다.

## 국내 DB 확인

ScholarCheck는 RISS, KCI, DBpia, KISS, e-Article을 자동 크롤링하지 않습니다.

대신 검색 조건을 URL 인코딩하여 국내 DB 직접 확인 링크를 제공합니다. 국내 DB 결과는 자동 검증 논문 목록에 포함하지 않습니다.

국내 DB 수동 확인 기록은 사용자가 직접 입력한 메모입니다. 자동 검증 결과가 아니며, 별도 CSV/JSON 내보내기와 백업 기능으로 관리합니다.

## 세션과 프로젝트

세션은 한 번의 검색 결과를 `data/sessions/`에 JSON으로 저장한 것입니다.

프로젝트는 여러 세션 ID를 `data/projects/`에 묶어 관리하는 단위입니다. 프로젝트는 원본 세션 JSON을 수정하지 않습니다.

프로젝트 통합 출력은 연결된 세션의 논문 행을 합쳐 보여줍니다. 중복 논문은 삭제하지 않고 `duplicate_candidate`로만 표시합니다.

누락된 세션 파일이 있어도 가짜 세션이나 논문을 만들지 않고 Missing Sessions 영역에 표시합니다.

## 출력물

세션 단위 출력:

- HTML 교수님 검토용 리포트
- Excel 통합 파일
- 참고문헌 후보
- 선행연구 매트릭스 초안
- CSV/JSON 검색 결과

프로젝트 단위 출력:

- 프로젝트 HTML 리포트
- 프로젝트 Excel 통합 파일
- 통합 논문 목록
- 중복 후보 목록
- 누락 세션 목록
- 국내 DB 수동 기록

## 제한 사항

ScholarCheck는 API 메타데이터 기반 검증 보조 도구입니다.

다음은 자동으로 확정하지 않습니다.

- 논문 존재의 최종 보증
- DOI의 최종 정답 여부
- PDF 접근 가능성의 기관별 차이
- 국내 DB 검색 결과의 실제 존재 여부
- 선행연구 매트릭스의 연구목적, 연구방법, 연구대상, 주요결과
- 참고문헌 후보의 최종 인용 형식

최종 논문 작성 전에는 원문 페이지와 기관 DB에서 직접 확인해야 합니다.
